Prueba del Primer Valor

¿El loop comienza donde se espera? El loop de Alex empieza en i = 0, pero Alex quería imprimir desde el 1.

¿El loop comienza en el valor correcto (1)?

¡Revisa otra vez! El loop empieza en i = 0, ¡no en 1! Eso significa que el primer número impreso será 0, no 1.
¡Exacto! El loop empieza en i = 0, pero debería comenzar en i = 1. Ese primer valor incorrecto es la raíz del problema.
Pregúntale a la IA: '¿Cuál es el valor de i en la primera iteración del loop?' Esa sola pregunta te revela el error.
👩‍🏫

Prueba del Último Valor

¿El loop se detiene en el valor final correcto? La condición es i < 5, así que el último valor de i es 4.

¿El loop termina en el valor correcto (5)?

¡Vuelve a verificar! Con i < 5, el loop se detiene cuando i llega a 5 — pero nunca imprime 5. El último valor impreso es 4.
¡Correcto! La condición i < 5 hace que el loop se detenga antes de imprimir 5. El loop imprime 0, 1, 2, 3, 4 — ¡nunca llega al 5!
Agrego un console.log al final... y veo que el último número es 4. ¡Eso está mal! Se suponía que imprimiera hasta el 5.
🧑‍💻

Prueba de Borde

¿Qué sucede en los límites del loop? Con i = 0 como inicio y i < 5 como condición, ¿cuántas iteraciones ocurren en total?

¿El loop ejecuta exactamente 5 iteraciones (sin más ni menos)?

¡Cuidado! El loop ejecuta 5 iteraciones (i = 0, 1, 2, 3, 4), pero los 5 valores son 0–4, ¡no 1–5! El conteo es correcto, pero los valores están desplazados.
¡Muy bien! Aunque el loop ejecuta exactamente 5 iteraciones, los valores están desplazados: 0, 1, 2, 3, 4 en lugar de 1, 2, 3, 4, 5. ¡El número de repeticiones está bien, pero el rango no!
Hay una diferencia entre 'número de iteraciones' y 'valores impresos'. Este loop itera 5 veces — ¡pero imprime los números incorrectos!
👩‍🏫

Verificación de Iteración Extra

¿El loop corre una vez de más accidentalmente? Con i = 0 y i < 5, obtenemos i = 0, 1, 2, 3, 4 — eso son 5 valores, pero incluye el 0.

¿El loop corre exactamente la cantidad correcta de veces sin iteraciones extra?

¡Espera! El loop imprime 0, 1, 2, 3, 4 — eso son 5 números, pero se pidió imprimir del 1 al 5. El 0 es una iteración extra que no debería estar.
¡Perfecto! El 0 es una iteración extra no deseada. Iniciando en i = 0 se obtiene un número más de lo que Alex quería — el código de la IA tiene un error clásico de uno de más.
Entonces, ¿la IA me dio un error de 'uno de más'? Si empezara en i = 1, ¡obtendría exactamente 1, 2, 3, 4, 5!
🧑‍💻

Verificación de Iteración Faltante

¿El loop se detiene demasiado pronto? La condición es i < 5, así que el 5 nunca se imprime. Alex quería imprimir del 1 al 5 — el 5 es el valor faltante.

¿El loop imprime todos los valores requeridos (1 al 5 inclusive)?

¡Revisa la consola! El 5 nunca aparece en la salida. Con i < 5, el loop se detiene cuando i = 4. El 5 es la iteración faltante.
¡Exacto! El número 5 nunca se imprime porque la condición i < 5 lo excluye. Para incluirlo, necesitaríamos i <= 5.
Siempre revisa si el último valor requerido aparece en la salida. Aquí, el 5 estará ausente — ese es el valor faltante.
👩‍🏫

Verificación de Coincidencia

¿La salida real coincide con lo que se solicitó? Alex le pidió a la IA que imprimiera los números del 1 al 5. La salida real es: 0, 1, 2, 3, 4.

¿La salida coincide exactamente con el comportamiento solicitado?

¡Mira más de cerca! Alex pidió 1, 2, 3, 4, 5 — pero la IA generó código que imprime 0, 1, 2, 3, 4. ¡No coincide en absoluto!
¡Perfecto! La salida real (0, 1, 2, 3, 4) no coincide con lo que se pidió (1, 2, 3, 4, 5). Es momento de pedirle a la IA que lo corrija: cambiar i = 0 a i = 1 y i < 5 a i <= 5.
Así que la IA no entendió bien el prompt, ¿verdad? Probablemente deba dar instrucciones más claras la próxima vez, como 'comienza en 1 e incluye el 5'.
